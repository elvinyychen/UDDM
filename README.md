# Unsupervised Diffusion-Based Degradation Modeling for Real-World Super-Resolution (UDDM)

Official implementation of **UDDM**, an unsupervised diffusion-based degradation modeling framework for real-world single-image super-resolution (SISR).

📄 **Paper:** [Unsupervised Diffusion-Based Degradation Modeling for Real-World Super-Resolution](https://ojs.aaai.org/index.php/AAAI/article/view/32235)  
📚 **Conference:** Proceedings of the AAAI Conference on Artificial Intelligence (AAAI-25)  
📖 **DOI:** [10.1609/aaai.v39i2.32235](https://doi.org/10.1609/aaai.v39i2.32235)

> **Code and resources:** This repository is being prepared. Installation instructions, pretrained weights, datasets, and evaluation scripts will be added as they become available.

## Overview

Real-world image degradation is complex and difficult to model using conventional synthetic degradation pipelines. Consequently, super-resolution (SR) models trained on synthetic low-resolution (LR) images often suffer from a domain gap when applied to real-world images.

This paper proposes **Unsupervised Diffusion-Based Degradation Modeling (UDDM)**, a framework that learns real-world degradation distributions from unpaired LR and high-resolution (HR) images.

The framework consists of two complementary degradation modules:

- **Diffusion-based Degradation Module (DDM):** Learns real-world degradation distributions by diffusing real-world LR images toward extremely low-resolution (ULR) images. Reverse diffusion is then used to generate realistic LR images from extremely downsampled HR images, without requiring paired LR-HR training data.
- **Physics-based Dynamic Degradation Module (P-DDM):** Models content-aware degradation using a physics-based degradation network and a parameter generation network. It adapts degradation operations to image content to preserve structural and textural fidelity.

The LR images generated by these two modules are adaptively fused to construct synthetic LR-HR training pairs. These pairs can then be used to train an SR model in a supervised manner.

The UDDM framework follows three stages:

1. **Train degradation modules.** Learn the real-world degradation distribution using unpaired LR and HR datasets by training DDM and P-DDM.
2. **Synthesize pseudo-pairs.** Generate realistic LR images from HR images using both degradation modules, then adaptively fuse their outputs.
3. **Train the super-resolution model.** Use the synthesized LR-HR pairs to train an SR network for real-world image restoration.

## Dependencies
- Python=3.9
- Pytorch == 1.12.1
- CUDA == 11.3
- pytorch-lightning == 1.4.2
- xformers == 0.0.22 (or below)
- Other required packages in `environment.yaml`

## Installation

```
# Create a conda environment and activate it
conda env create --file environment.yaml
conda activate ddm

# Install xformers
conda install xformers -c xformers/label/dev

# Install taming & clip
pip install -e git+https://github.com/CompVis/taming-transformers.git@master#egg=taming-transformers
pip install -e git+https://github.com/openai/CLIP.git@main#egg=clip
pip install -e .
```

## Training
Use the following script to train the Diffusion-based Degradation Model (DDM).
```
python main.py --train --base configs/stableSRNew/v2-finetune_text_T_512_degrade.yaml --gpus 0,1,2 --name degrade_realsr
```
